My music — tabs & sheets

Text tabs (.txt), Guitar Pro 7/8 (.gp), MusicXML (.musicxml / .mxl — export it from MuseScore, Sibelius…) or PDF. Older .gp5 / .gpx files: open them in MuseScore (free) and export MusicXML.

🔎 Find tabs online

Search a tab site for any song, copy a text tab, then come back and tap 📋 Paste tab. Section labels like [Verse] or Chorus: become buttons to loop that part, chord names written above the tab are played by the chords layer, and repeat marks (x4) are played out. Tabs you paste stay on this device.

Sheet music → MusicXML setup

Printed notation in a PDF is converted by Audiveris (free, open-source music recognition) running as a GitHub Action in your groove-metronome repository. One-time setup:

  1. Create a fine-grained token: Repository access → only your groove-metronome repository; Permissions → Contents: Read and write.
  2. Enter the repository and the token below. The token is stored only on this device.

If the repository is public, the PDFs you convert and the results are public too. To keep them private, copy .github/ and omr/ from the app repository into a private repository and enter that one instead.
