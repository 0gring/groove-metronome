# Instrument samples

All CC0 (public domain). Each note: mono, onset-trimmed, shortened with a fade-out, peak-normalized, FLAC.
`manifest.json` lists `sus` (ringing), `stac` (short) and `dead` samples; `[midi, measured pitch]` per note
is used for tuning correction. Octave numbering differs between libraries, so every note was checked against
its measured pitch (harmonic-sum and autocorrelation).

| Folder | Source |
|---|---|
| `fbass/` | Squier Jazz Bass — Karoryfer Growlybass (sfzinstruments/karoryfer.growlybass) |
| `upright/` | Double bass pizzicato + percussive dead notes — Karoryfer Meatbass (sfzinstruments/karoryfer.meatbass) |
| `guitar/` | Gretsch Anniversary — Karoryfer Black And Green Guitars (sfzinstruments/karoryfer.black-and-green-guitars) |
| `trumpet/`, `flute/` | VSCO 2 Community Edition (sgossner/VSCO-2-CE) |
| `sax/`, `vibes/` | Versilian Community Sample Library (sgossner/VCSL): tenor saxophone, vibraphone |
